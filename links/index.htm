Ссылки по теме магистерской работы

Аннотированный перечень интернет-ресурсов по теме «Гибридный метод аудита безопасности смарт-контрактов на основе статического анализа и фаззинга с оценкой полноты обнаружения». Все ссылки проверены на работоспособность на момент публикации сайта.

1. Научные ресурсы и базы публикаций

  • 1. arXiv.org Крупнейший открытый архив препринтов; раздел cs.CR — компьютерная безопасность, работы по аудиту смарт-контрактов.
  • 2. Google Scholar Поисковик научных публикаций: статьи по статическому анализу и фаззингу смарт-контрактов, цитирования, h-индекс.
  • 3. IEEE Xplore Цифровая библиотека IEEE: ключевые публикации по безопасности блокчейн-систем (ICSE, S&P, ASE).
  • 4. ScienceDirect База издательства Elsevier: журналы по компьютерной безопасности и разработке ПО.
  • 5. КиберЛенинка Русскоязычная научная библиотека открытого доступа: статьи по смарт-контрактам и блокчейну.
  • 6. eLibrary.ru Российский индекс научного цитирования (РИНЦ).

2. Инструменты статического анализа

  • 7. Slither (Trail of Bits) Статический анализатор Solidity: taint-анализ, обнаружение 90+ классов уязвимостей, детектор ошибок компилятора. Базовый инструмент гибридного аудита.
  • 8. Mythril (Consensys) Символьный анализатор EVM-байткода: находит реентрабельность, целочисленные переполнения, доступ к незащищённым функциям.
  • 9. Oyente Классический анализатор на символьном выполнении (2016); проверка торовых границ газа, реентрабельности, транзакционных зависимостей.
  • 10. Securify v2 (ETH Zurich) Анализатор, основанный на DSL для спецификаций фактов безопасности о коде контрактов; масштабируется на большие контракты.
  • 11. SmartCheck (SmartDec) Статический анализатор на основе XML-правил: синтаксические и семантические уязвимости контрактов Solidity.
  • 12. Solhint Линтер Solidity: правила безопасности (SWC), стилевые рекомендации; интегрируется в CI и IDE.

3. Фаззинг и формальная верификация

  • 13. Echidna (Trail of Bits) Property-based фаззер для EVM: тестирует инварианты контракта последовательностями транзакций; ядро фаззинг-компоненты аудита.
  • 14. Foundry (forge fuzz) Инструментарий для разработки на Solidity: встроенный фаззинг-режим forge test, invariant-тесты, быстрые тесты на Solidity.
  • 15. Medusa (Trail of Bits) Параллельный фаззер на Go с интерактивным исследованием покрытия; подходит для исследования стратегий фаззинга EVM.
  • 16. Manticore Символьный движок для анализа EVM и бинарников: построение путей выполнения, доказательство свойств на конкретных функциях.
  • 17. Certora Prover Формальная верификация смарт-контрактов: спецификации CVL, доказательство соответствия контракта формальным правилам.

4. Классификации уязвимостей и лучшие практики

  • 18. SWC Registry Реестр классификации слабых мест смарт-контрактов (SWC-100…SWC-136): реентрабельность, контроль доступа, арифметика — основа оценки полноты обнаружения.
  • 19. ConsenSys: Smart Contract Best Practices Рекомендации по безопасной разработке: известные атаки, шаблоны защиты, чек-листы аудита.
  • 20. Solidity: Security Considerations Официальный раздел документации Solidity об угрозах: реентрабельность, front-running, ограничения газа при передаче адресов.
  • 21. DASP Top 10 Топ-10 уязвимостей децентрализованных приложений по данным Audit.io; историческая классификация атак на смарт-контракты.
  • 22. Rekt News Разборы крупнейших взломов DeFi: причины, суммы ущерба, уроки для методик аудита.
  • 23. Not So Smart Contracts Библиотека антипаттернов Solidity от Trail of Bits с примерами уязвимого кода и способами устранения.

5. Практические площадки и обучение

  • 24. Ethernaut (OpenZeppelin) Интерактивная игра-тренажёр: взлом обучающих контрактов для отработки навыков поиска уязвимостей.
  • 25. Damn Vulnerable DeFi Серия усложняющихся заданий по безопасности DeFi: от простых багов до комбинированных атак.
  • 26. Secureum Bootcamp и рассылка по безопасности смарт-контрактов: дайджесты уязвимостей, разборы инструментов, квизы.
  • 27. OpenZeppelin Contracts Эталонная библиотека аудированных контрактов (ERC-20/721, AccessControl, Pausable) — образец безопасных реализаций.

6. Датасеты и методические материалы

  • 28. SmartBugs Фреймвор для исполнения анализаторов на уязвимых контрактах + датасет из нескольких тысяч контрактов с разметкой.
  • 29. SmartBugs-curated Курируемый датасет уязвимых контрактов с точной разметкой уязвимостей по SWC — стандартная база для оценки полноты обнаружения.
  • 30. Building Secure Contracts (Trail of Bits) Методические материалы: руководства по Echidna, Slither, инвариантам и практиккам гибридного аудита.
