Links on the master's thesis topic

An annotated list of web resources on the topic “Hybrid method for smart contract security auditing based on static analysis and fuzzing with detection completeness evaluation”. All links were checked and working at the time the site was published.

1. Scientific resources and publication databases

  • 1. arXiv.org The largest open preprint archive; the cs.CR section covers computer security and smart contract auditing papers.
  • 2. Google Scholar A search engine for scholarly publications on static analysis and smart contract fuzzing, citations, h-index.
  • 3. IEEE Xplore IEEE digital library: key publications on blockchain systems security (ICSE, S&P, ASE).
  • 4. ScienceDirect Elsevier's database: journals on computer security and software engineering.
  • 5. CyberLeninka Russian-language open-access scientific library: papers on smart contracts and blockchain.
  • 6. eLibrary.ru Russian Science Citation Index (RSCI).

2. Static analysis tools

  • 7. Slither (Trail of Bits) A Solidity static analyzer: taint analysis, detection of 90+ vulnerability classes, compiler bug detector. The core tool of hybrid auditing.
  • 8. Mythril (Consensys) A symbolic execution analyzer of EVM bytecode: finds reentrancy, integer overflows, unprotected functions.
  • 9. Oyente The classic symbolic execution analyzer (2016): checks gasless send, reentrancy, transaction-ordering dependence.
  • 10. Securify v2 (ETH Zurich) An analyzer built on a DSL for security facts about contract code; scales to large contracts.
  • 11. SmartCheck (SmartDec) A rule-based static analyzer (XML rules): syntactic and semantic vulnerabilities of Solidity contracts.
  • 12. Solhint A Solidity linter: security rules (SWC), style recommendations; integrates into CI and IDEs.

3. Fuzzing and formal verification

  • 13. Echidna (Trail of Bits) A property-based fuzzer for the EVM: tests contract invariants with transaction sequences; the core of the fuzzing component.
  • 14. Foundry (forge fuzz) A Solidity development toolkit: built-in fuzzing mode of forge test, invariant tests, fast Solidity tests.
  • 15. Medusa (Trail of Bits) A parallel fuzzer written in Go with interactive coverage exploration; suitable for EVM fuzzing strategy research.
  • 16. Manticore A symbolic execution engine for the EVM and binaries: path exploration and proving properties of specific functions.
  • 17. Certora Prover Formal verification of smart contracts: CVL specifications, proving that a contract satisfies formal rules.

4. Vulnerability classifications and best practices

  • 18. SWC Registry The Smart Contract Weakness Classification registry (SWC-100…SWC-136): reentrancy, access control, arithmetic — the basis for detection completeness evaluation.
  • 19. ConsenSys: Smart Contract Best Practices Recommendations for secure development: known attacks, defense patterns, audit checklists.
  • 20. Solidity: Security Considerations The official Solidity documentation section on threats: reentrancy, front-running, gas limits on address transfers.
  • 21. DASP Top 10 Top 10 decentralized application vulnerabilities; a historical classification of smart contract attacks.
  • 22. Rekt News Investigations of the largest DeFi hacks: causes, damage amounts, lessons for audit methodologies.
  • 23. Not So Smart Contracts A library of Solidity anti-patterns from Trail of Bits with examples of vulnerable code and fixes.

5. Practice platforms and training

  • 24. Ethernaut (OpenZeppelin) An interactive wargame: hacking training contracts to practice vulnerability hunting skills.
  • 25. Damn Vulnerable DeFi A series of increasingly difficult DeFi security challenges: from simple bugs to combined attacks.
  • 26. Secureum A smart contract security bootcamp and newsletter: vulnerability digests, tool reviews, quizzes.
  • 27. OpenZeppelin Contracts The reference library of audited contracts (ERC-20/721, AccessControl, Pausable) — a model of secure implementations.

6. Datasets and methodological materials

  • 28. SmartBugs A framework for running analyzers on vulnerable contracts plus a dataset of several thousand annotated contracts.
  • 29. SmartBugs-curated A curated dataset of vulnerable contracts with precise SWC vulnerability annotation — the standard base for detection completeness evaluation.
  • 30. Building Secure Contracts (Trail of Bits) Methodological materials: guides to Echidna, Slither, invariants and hybrid auditing practices.
