Golang-разработка

Электронный учебно-методический комплекс по дисциплине Б1.О.15 «Golang-разработка» для направления подготовки 01.03.02 «Прикладная математика и информатика». Комплекс содержит аннотацию курса, рабочую учебную программу, теоретический материал (4 лекции) и практические работы (4 лабораторные).

О дисциплине

Цель: формирование теоретических знаний и практических навыков разработки программного обеспечения на языке Go, включая работу с составными типами данных, интерфейсами, средствами параллельного программирования и созданием веб-сервисов.

Основные задачи:

  • освоить инструментарий экосистемы Go (go mod, go test, gofmt, go vet);
  • изучить синтаксис и систему типов языка, принципы организации пакетов;
  • овладеть работой со слайсами, мапами, структурами и интерфейсами;
  • освоить параллельное программирование: горутины, каналы, sync, context;
  • научиться разрабатывать REST API на основе net/http и тестировать приложения.

Объём: 2 зачётные единицы (72 часа).

Тестирование по курсу

Для проверки знаний по дисциплине «Golang-разработка» предлагается пройти итоговый тест. Тест включает 10 заданий по всем разделам курса. Результат и оценка отображаются сразу после завершения — вместе с пояснениями к каждому вопросу.

Инструкция к тестированию

Перед началом теста убедитесь в удобном рабочем месте. Каждое задание оценивается в 1 балл; балл начисляется только при выборе единственного верного варианта. Шкала оценивания: 9–10 — «отлично», 7–8 — «хорошо», 5–6 — «удовлетворительно», менее 5 — «неудовлетворительно». Результат и оценка появляются автоматически после нажатия кнопки «Проверить».
