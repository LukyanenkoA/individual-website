# individual-website

Индивидуальный (персональный) сайт магистранта КубГУ **Лукьяненко Аллы Андреевны**
(факультет компьютерных технологий и прикладной математики, кафедра информационных технологий,
направление 01.04.02 «Прикладная математика и информатика»).

**Адрес:** <https://lukyanenkoa.github.io/individual-website/>

## Структура сайта

| Раздел | Путь | Языки |
|---|---|---|
| Биография | `index.html` / `indexe.htm` | RU / EN |
| Реферат | `diss/` | RU / EN |
| Библиотека (публикации, свидетельства ЭВМ) | `library/` | RU / EN |
| Ссылки по теме | `links/` | RU / EN |
| Отчёт о поиске | `links/zvit.htm`, `links/zvite.htm` | RU / EN |
| Индивидуальный раздел (волонтёрство) | `ind/` | RU / EN |
| ЭУМК «Golang-разработка» (лекции, лабы, тест) | `eumk/` | RU / EN |

## Тема магистерской работы

«Гибридный метод аудита безопасности смарт-контрактов на основе статического
анализа и фаззинга с оценкой полноты обнаружения».

Научный руководитель — Харченко Анна Владимировна, канд. пед. наук, доц.

## Технические детали

- Статический HTML + CSS (кастомная тема), Bootstrap 5 (CDN)
- `tools/gen_eumk.py` — генерация PDF-документов ЭУМК (reportlab)
- `tools/gen_rup.py` — генерация рабочей учебной программы (reportlab)
- Встроенный тест по курсу: `eumk/test.htm` / `eumk/teste.htm` (чистый JS)

## Локальный запуск

```bash
python -m http.server 8000
# http://127.0.0.1:8000
```
